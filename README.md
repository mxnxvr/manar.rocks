# manar.rocks

A pixel-art operating system that doubles as my portfolio.

**Live:** https://manar.rocks


## What's inside

- **ManarOS:** windows, a dock, and apps: About me, Projects, Terminal, Chess, Doodle (a pixel-art editor) and Cloudsweeper.
- **Doki:** the resident security cat. Click for advice of questionable usefulness.
- **Sound:** soft UI sounds and a faint lo-fi loop, all generated live in the browser.

## Capture the flag

There are **9 flags** hidden across the system, in the format `manar{...}`.
Open the CTF app to track your progress. Start with `about_me.txt`.


## Built with

One `index.html` file: HTML, CSS and plain JavaScript. No frameworks, no build step, no tracking.
The scenes, icons and sounds are all drawn and synthesised in code (Canvas and Web Audio).
Chess moves are checked by [chess.js](https://github.com/jhlywa/chess.js).
